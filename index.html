    Full Stack Developer

    Savage Global Marketing
    Florida, USA · Remote
    StackFlutter · .NET · REST APIs

    Built the mobile version of an internal client management platform — a two-sided system used by the agency's team to manage tasks, productions and client deliveries, and by clients to track their projects in real time.

    Context

    I joined the project to build the mobile application using FlutterFlow. The visual layer progressed quickly, but as backend integrations grew and business rules became more complex, state management started introducing significant technical limitations. The project lost scalability and feature evolution became compromised.

    Decision

    Rather than pushing forward with a solution that would only increase technical debt, I analyzed the situation, documented the main issues in a technical report, and presented alternatives for moving the project forward. From there, I proposed exporting the FlutterFlow code and migrating to pure Flutter, adopting a modular, feature-based architecture to improve maintainability, organization, and scalability.

    Result

    The migration was completed within a tight deadline, preserving the project's deliveries and allowing the app to evolve sustainably again. The initiative for the change, as well as the definition of the new architecture, came from me.
